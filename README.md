# Using OpenStreetMap for Urban Spatial Analysis

A comprehensive workshop introducing OpenStreetMap (OSM) data and analysis techniques for urban research applications. This presentation covers OSM fundamentals, data acquisition methods, and practical implementation using OverpassQL queries.

## 🌐 Live Presentation

**View the interactive slides:** [felipevaldez.com/osm_for_urban_analysis](https://felipevaldez.com/osm_for_urban_analysis/)

## 📚 Workshop Contents

- **OSM Fundamentals**: Data structure, elements (nodes, ways, relations), and tagging systems
- **Data Acquisition**: Multiple methods for downloading OSM data
  - Overpass Turbo with OverpassQL queries
  - Alternative download methods and tools
- **Spatial Filtering**: Bounding boxes, named areas, and proximity searches
- **Practical Applications**: Real-world examples for urban research
- **Hands-on Exercises**: Interactive demonstrations and query building

## 📖 Resources

- [OpenStreetMap](https://openstreetmap.org) - The free wiki world map
- [Overpass Turbo](https://overpass-turbo.eu/) - Web-based data mining tool
